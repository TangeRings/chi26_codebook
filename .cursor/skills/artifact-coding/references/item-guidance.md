# Item-Type Guidance

**Version:** v1 (order-invariant revision)
**Status:** General conceptual guidance by item type. Not a per-question skill. Apply alongside the codebook and decision rules.

## General principle

Every item type is aligned globally. Position never carries semantic meaning.

- Treat list items, descriptors, values, clauses, and sentences as members of unordered conceptual sets.
- Match by semantic function and conceptual continuity across the full PRE and POST sets.
- Reordering alone produces no semantic event (ORDER-vs-SEMANTIC).
- New and Removed are last-resort classifications after a full-response search (LAST-RESORT-NEW-REMOVED).

---

## Brand Identity / descriptor lists

Applies to short brand-characteristic or identity-descriptor responses (e.g. keyword lists of traits).

- Treat descriptors as an **unordered conceptual set**.
- Perform **global alignment** across the full PRE and POST sets.
- List order has no meaning. Reordering alone produces no semantic event.
- Vague descriptors may become more concrete in POST. Apply VAGUE-vs-SPECIFIC before Removed + New.
- Conceptual refinement may be Narrowed or Reframed depending on whether scope or frame changes.
- New / Removed only after global matching fails and a full-response search finds no plausible lineage.

**Do not:**
- Map PRE descriptor #1 → POST descriptor #1 by index.
- Treat rearranged synonyms as Reframed.
- Code order polish as Elaborated.

---

## Core Values / value lists

Applies to brand-value or guiding-principle lists.

- Treat values as an **unordered conceptual set**.
- Do not align by index.
- Allow cross-position mapping. A concept moved from first to second position is still the same lineage candidate.
- Reordering alone is not semantic.
- Use New only when no plausible PRE value antecedent exists anywhere in the set.
- Use Removed only when no plausible POST successor exists anywhere in the set.
- If two PRE values and two POST values share no conceptual continuity after global matching, prefer distinct Removed and New events — not positional Reframed pairs invented by list index.

---

## Narrative responses

Applies to extended prose (brand vision, customer description, product narrative, etc.).

- Sentence order may change between PRE and POST.
- Align by concept, not sentence number.
- Moved clauses can still be semantically continuous.
- Reorganisation without change in propositional content is not Reframed.
- A semantic successor may appear in a very different location in POST; position is weak evidence, conceptual role is strong evidence.

**Example pattern:**
PRE sentence 1 contains concept A; PRE sentence 2 contains concept B.
POST sentence 1 contains B'; POST sentence 3 contains A'.
Align A→A' and B→B' if conceptual continuity is stronger than positional similarity.

---

## Target Customer

Applies to audience / demographic / psychographic descriptions.

- Attend to category extension and scope.
- `individuals` → `enthusiasts` = Narrowed (population restricted).
- Longer wording does not imply Elaborated.
- Order of demographic or psychographic details does not matter.
- Vague audience labels that become more concrete should be checked under VAGUE-vs-SPECIFIC before Removed + New.
